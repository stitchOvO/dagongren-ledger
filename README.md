# 🐷 打工人小账本

> 离线个人记账户台 · 数据存本地 · 三端可用 · 无需服务器

## ✨ 功能

| 模块 | 说明 |
|------|------|
| ⏱ **真实时薪** | 综合到手月薪、发薪月数、工作成本、在场时间、通勤、加班，展开完整公式 |
| ⚡ **闪电记账** | 快捷金额 + 分类点选 + 回车即存，自动换算工时成本 |
| 📊 **月度小结** | 收入/固定支出/弹性支出/结余，一目了然 |
| 🎯 **存款目标** | 自由基金（FIRE 4% 法则）+ 安全垫，SVG 曲线追踪 |
| 🎛 **情景模拟** | 通勤/加班/涨薪滑块，独立计算时薪变化 |
| 🔄 **跨设备同步** | 同步码复制粘贴 + JSON 导入导出，PC 版支持云盘文件同步 |
| 📱 **三端适配** | PC 侧栏 / 安卓 MD3 / iOS SF 毛玻璃，各自原生风格 |

## 🚀 使用

直接打开对应 HTML 文件即可，无需安装任何东西：

| 文件 | 平台 |
|------|------|
| `index.html` | 首页（版本选择） |
| `打工人小账本-PC.html` | Windows / Mac |
| `打工人小账本-安卓.html` | Android |
| `打工人小账本-iOS.html` | iPhone / iPad |

所有数据保存在浏览器 localStorage 中，不上传任何服务器。跨设备使用「同步码」或 JSON 文件传输。

## 🛠 技术

- 纯静态 HTML/CSS/JS，单文件架构
- 零依赖：无 CDN、无框架、无后端
- SVG 手绘图表（存款曲线、小猪存钱罐）
- localStorage 紧凑存储（体积压缩 ~40%）
- iOS 毛玻璃 + Android MD3 + PC 侧栏，CSS 全内联
